# How to cite

If you use `rnel`, please cite the software and the paper that defines the logic.

## Software

Version 0.2.0 is archived on Zenodo:

> Leyva-Vázquez, M. Y., & Smarandache, F. (2026). *rnel: Refined Neutrosophic Evidential Logic* (Version 0.2.0)
> [Computer software]. Zenodo. <https://doi.org/10.5281/zenodo.23040628>

```bibtex
@software{rnel_0_2_0,
  author    = {Leyva-Vázquez, Maikel Yelandi and Smarandache, Florentin},
  title     = {rnel: Refined Neutrosophic Evidential Logic},
  version   = {0.2.0},
  year      = {2026},
  publisher = {Zenodo},
  doi       = {10.5281/zenodo.23040628},
  url       = {https://github.com/mleyvaz/rnel}
}
```

The repository contains a [`CITATION.cff`](https://github.com/mleyvaz/rnel/blob/master/CITATION.cff) file, so
GitHub's "Cite this repository" button gives the same reference in APA and BibTeX.

## Paper

> Smarandache, F., & Leyva-Vázquez, M. Y. (2026). *The Neutrosophic (T, I, N, F), Multi-Uncertainty, n-Valued
> Refined, and Refined Evidential Logics with Neutrosophic Probability as Extensions of Subjective Logic*.
> Preprints. <https://doi.org/10.20944/preprints202609.2584.v1> (under review)

```bibtex
@misc{smarandache_leyva_2026_rnel,
  author = {Smarandache, Florentin and Leyva-Vázquez, Maikel Yelandi},
  title  = {The Neutrosophic (T, I, N, F), Multi-Uncertainty, n-Valued Refined, and Refined Evidential Logics
            with Neutrosophic Probability as Extensions of Subjective Logic},
  year   = {2026},
  howpublished = {Preprints},
  doi    = {10.20944/preprints202609.2584.v1},
  note   = {Preprint, under review}
}
```
